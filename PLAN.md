# IELTS Tutor — план проекта

Цель: построить систему Claude Code субагентов, которая может принимать
IELTS-экзамен (Reading/Listening/Speaking/Writing), оценивать, обучать,
давать советы и генерировать упражнения — на основе анализа всех видео
канала **IELTS Advantage** (https://www.youtube.com/@Ieltsadvantage).

Этот файл — неизменный план. Текущий статус и прогресс см. в `STATUS.md`
(обновляется по ходу работы, читай его первым при возвращении к задаче).

## Итоговая архитектура

```
.claude/agents/
  ielts-tutor.md       <- главный оркестратор (верхний уровень)
  ielts-reading.md      <- специалист Reading
  ielts-listening.md    <- специалист Listening
  ielts-speaking.md     <- специалист Speaking
  ielts-writing.md      <- специалист Writing
```

**Главный агент (ielts-tutor)**: охватывает все 4 направления, умеет:
- давать советы по любому аспекту IELTS;
- сам создавать вопросы/задания любого раздела;
- оценивать Writing и Speaking (band score + фидбек);
- генерировать Reading-текст с вопросами и оценивать ответы;
- для Listening — объяснять типы вопросов, стратегии решения, как развивать навык;
- делегировать специализированные задачи 4 субагентам-специалистам, когда
  нужна более глубокая, узкая работа по одному разделу.

**4 специалиста** — каждый заточен под один раздел, и внутри знает 4 режима:
обучение (training), приём экзамена (exam), советы (advice), фишки (tips).
Их системные промпты строятся на анализе реального контента канала
(`data/analysis/<section>.md`), а не на общих знаниях об IELTS.

## Пайплайн сборки (этапы)

1. **Собрать список всех видео канала** — через uploads playlist (yt-dlp
   flat-playlist). Готово: `data/raw/uploads.json` (421 записей: id, title,
   duration).
2. **Скачать метаданные + транскрипты** для каждого видео (описание,
   дата публикации, субтитры) — скрипт `scripts/scrape.py`. Транскрипты
   качаются только для видео >=90с (шортсы обычно без развёрнутого контента).
   Разложено по `data/raw/info/<id>.json` и `data/raw/subs/<id>.vtt`.
3. **Собрать один MD-файл на видео** — `scripts/build_video_md.py` строит
   `data/videos/<id>.md` (заголовок, ссылка, длительность, дата, описание,
   транскрипт).
4. **Классификация**: каждое видео получает раздел (Reading/Listening/
   Speaking/Writing — или `general`, если видео не привязано к одному
   навыку, напр. мотивационное/про формат экзамена) и подтип (training /
   exam / advice / tips, можно несколько). Результат — `data/catalog.md`
   (таблица для людей) + `data/classification.json` (машиночитаемо).
   Выполняется батчами через subagent (Agent tool), т.к. 421 видео вручную
   не классифицировать в одном проходе.
5. **Анализ по разделам**: для каждого из 4 разделов отдельный subagent
   читает все видео этого раздела и пишет `data/analysis/<section>.md` —
   методология канала, типичные вопросы, критерии оценки, советы, фишки,
   примеры формулировок.
6. **Создание агентов**: `.claude/agents/ielts-{reading,listening,speaking,
   writing}.md` на основе анализа, плюс `.claude/agents/ielts-tutor.md`
   (оркестратор).
7. **Commit & push** в ветку `claude/clever-galileo-9k9c0v`.

## Известный блокер: антибот-блокировка YouTube

Общий исходящий IP этого облачного окружения иногда попадает под капча-стену
Google (`HTTP 302 → google.com/sorry/index`). Это IP-репутационная
блокировка на уровне Google, а не зависящая от конкретного клиента (curl /
requests / yt-dlp — без разницы) и не фиксящаяся через настройки сетевого
доступа окружения (youtube.com уже разрешён).

Решение (выбрано пользователем): **ждать и медленно повторять**.
`scripts/scrape.py` при обнаружении блока не гонит быстрые ретраи, а спит
~25 минут и повторяет тот же запрос, потенциально много раз подряд. Между
обычными (не блокированными) запросами пауза 20-35 секунд. Скрипт
идемпотентен/resumable — пропускает уже скачанные id, можно убивать и
перезапускать в любой момент без потери прогресса.

## Важные пути

- `scripts/scrape.py` — скрапер метаданных+транскриптов (durable, resumable)
- `scripts/build_video_md.py` — собирает data/videos/<id>.md из raw-данных
- `data/raw/uploads.json` — полный список видео канала (421 записей)
- `data/raw/info/<id>.json` — метаданные видео (после скрапинга)
- `data/raw/subs/<id>.vtt` — транскрипт видео (после скрапинга, только >=90с)
- `data/raw/scrape.log` — лог скрапера
- `data/videos/<id>.md` — собранный MD по видео
- `data/catalog.md`, `data/classification.json` — классификация
- `data/analysis/{reading,listening,speaking,writing}.md` — анализ по разделам
- `.claude/agents/*.md` — финальные агенты
