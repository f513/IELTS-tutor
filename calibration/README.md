# Калибровка оценок

Набор ответов с **известной** оценкой. Тьютор оценивает каждый ≥3 раз;
допуск ±0.5 band, систематический сдвиг в одну сторону = провал.
Задачи: [[P3-1 Эталон band 9]] · [[P3-2 Калибровочный набор]] · [[P3-3 Прогон калибровки]].

**Правило авторских прав:** официальные тексты не копируем — храним ссылку,
оценку экзаменатора и наш разбор.
